# Splice 视频拼接工具 — 稳定性增强版

`.NET 10 / C# 14 / WPF / CommunityToolkit.Mvvm 8.4.2 / MaterialDesignThemes 5.3.2 / Serilog`

## 使用方法

1. 使用 Visual Studio 2026（安装 .NET 桌面开发及 .NET 10 SDK）打开 `Splice.slnx`。
2. 将适用于 Windows x64 的 FFmpeg 静态版本 `ffmpeg.exe` 放进 `Tools/ffmpeg.exe`。源码 ZIP **不含** FFmpeg 二进制。
3. 按 F5。要发布时使用 Visual Studio 原生“发布”，无需 BAT。发布配置会检查 FFmpeg 是否存在并自动带上 `Tools/ffmpeg.exe`。
4. 选择下载目录中的多个文件夹（或导入父目录），设置 MP4 输出路径，点击“开始合并”。程序一次只运行一个 FFmpeg 任务，异步读取进度，不需要用户配置 FFmpeg 路径。

## 本次稳定性改造

- 新增 `MergeErrorReason` 和 `MergeFailureException`，包含错误类别、是否暂停队列、退出码和技术诊断。
- `FileValidationService`：检查 HLS 清单可读且以 `#EXTM3U` 开头，并试探输出目录写入权限。
- `DiskSpaceService`：可查询空间时至少保留 256 MiB 安全余量。**这不是视频大小精确预估**，视频很大时仍可能在合并过程中写满磁盘；届时依靠 FFmpeg stderr 和系统错误代码判别。
- `ExceptionHandlerService`：区分磁盘满、权限、输出设备、损坏的播放列表、源文件丢失、FFmpeg 错误与未知故障。磁盘满或输出持续无法写入暂停整个队列；单集问题继续下一集。网络共享若无法查询剩余空间，则跳过预检，但仍捕获写入错误。
- 每个任务继续使用 GUID 临时 MP4；只在退出码为 0 且文件非空后重命名为最终文件，绝不覆盖已有视频。
- 取消以及异常退出时先尝试终止 FFmpeg 进程并等待退出；确认停止后才清理未完成的临时视频。若不能确认进程终止，会保留临时文件并记录路径以避免数据竞争。
- 新增 Material Design 提示框：磁盘满等全局故障时解释原因；关闭窗口正在合并时提示继续还是停止并退出。
- ViewModel 保留一条一条依次处理的队列；修复输出问题后可重新开始未完成/失败任务，成功的任务不重复执行。
- 保留科技蓝单页 WindowChrome、用户上传的 `Splice.png`、配套 `Splice.ico`、PackIcon 操作图标、无额外字体与 SVG、目录记忆和日志写入 `%LOCALAPPDATA%/Splice/Logs/`。

## 重要说明

- 源码 ZIP 未包含 FFmpeg，使用方需自行加入其合法分发构建，遵循 FFmpeg 与所选构建许可证。
- 不尝试绕过 DRM；受保护或密钥不可用的流可能无法合并。
- `256 MiB` 是保守下限，不保证剩余空间一定足够。如果输出盘剩余空间远超 256 MiB，但仍小于视频最终大小，FFmpeg 会在写入时报告错误；应用会尝试识别并暂停队列。
- 用户突然结束进程、Windows 强制关机或断电时，程序无法保证回调清理，可能遗留 `.splice.tmp.mp4`，应在确认程序退出后手动检查。
- 只检查合并后文件非空，不保证媒体文件的每一帧都可播放。必要时可后续加入 `ffprobe` 校验。
- 当前环境没有 Windows 和 .NET SDK，已做静态检查，**尚未完成 Windows 编译与真实磁盘满场景测试**。请先在 VS 运行下文测试矩阵。

## Windows 手工验收建议

| 场景 | 期望结果 |
| --- | --- |
| 正常多个下载文件夹 | 顺序处理，输出 `文件夹名.mp4`，界面可操作 |
| 文件夹名以 `.m3u8` 结尾 | 输出无双扩展名 |
| 删除某个分片 | 该任务失败并写日志，其余正常任务继续 |
| 损坏 `index.m3u8` | 提示播放列表无效，继续其它任务 |
| 把输出指定为无权限目录 | 显示输出目录权限错误，队列暂停 |
| 输出盘容量不足 | 预检或写入失败后暂停队列，已完成文件保留 |
| 写入时拔掉移动硬盘 | 该任务失败，输出位置不可用时暂停队列 |
| 正在合并时关闭窗口 | 弹出关闭确认，“继续合并”不退出，“停止并退出”取消且等待进程结束 |
| 点击停止 | 当前 FFmpeg 停止，临时文件清理，程序保持运行 |
| 同名视频已存在 | 自动另取序号，不覆盖原视频 |
| FFmpeg 丢失 | 不启动合并，显示缺失提示 |
| 下次启动 | 自动恢复上次的输入起始位置与 MP4 输出目录 |

**日志：** `%LOCALAPPDATA%\Splice\Logs`。诊断包含原始 FFmpeg stderr（最多保留 80 行用于错误分类，全量写 Serilog）。
